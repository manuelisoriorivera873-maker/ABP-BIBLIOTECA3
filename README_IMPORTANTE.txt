BIBLIOTECA 3 - ENTREGA CORREGIDA

Archivos incluidos:
- ALTERACIONES_BIBLIOTECA3.sql
- Documento_Alteraciones_Biblioteca3.rtf

Aplicacion recomendada:
1. Respaldar la base de datos actual.
2. Ejecutar ALTERACIONES_BIBLIOTECA3.sql en MySQL / phpMyAdmin.
3. Verificar que existan las tablas de cuentas y permisos si el proyecto ya las usa.
4. Probar modulo de Autores, Libros, Devoluciones y Cuentas y permisos.

Cambios importantes:
- Autores enlazado con Personas.
- Devoluciones con detalle_devolucion.
- Mejoras visuales generales.
- Matriz de permisos rediseñada.
